# NZ ERA dismissal decisions — 2010–2025

Classification of public New Zealand Employment Relations Authority dismissal determinations.

![Outcome classification by year](output/charts/outcomes_by_year.png)

## Key results

- **2010–2019 strict audit:** 4,038 determinations reviewed; 2,373 substantive dismissal-merits decisions; 1,449 employee wins; 924 employer wins; **61.1% employee win rate**.
- **2025:** 234 PDFs; 173 possible merits decisions; 75 employee wins, 16 employer wins, 82 mixed/unclear. Employee win rate is **43.4%** including mixed outcomes or **82.4%** among clear employee/employer outcomes.
- The 2010–2019 strict audit resolves included merits cases to employee/employer outcomes. The 2020–2025 dataset retains mixed/unclear outcomes where appropriate.
